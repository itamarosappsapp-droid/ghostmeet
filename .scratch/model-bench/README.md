# Стенд сравнения моделей

[bench.html](bench.html) — локальная страница: один и тот же вопрос уходит выбранным моделям **тем же промптом, что и из приложения**, потоком, параллельно.

```bash
open .scratch/model-bench/bench.html
```

## Что она делает

- Тянет каталог моделей прямо у Polza.AI (`/api/v1/models` открыт без ключа) и считает цену **за одно нажатие в приложении** — примерно 10 000 входных токенов и 400 выходных.
- Подставляет настоящий системный промпт: §9 из `docs/GhostMeet-Prompts.md`, жанр «коротко», плюс блоки профиля и заготовок ровно так, как их клеит `PromptFragment.system`. Промпт правится прямо на странице — так видно, какая правка чинит, а какая нет.
- Шлёт всем выбранным моделям параллельно, потоком, и показывает время до первого токена, общее время, число кусков потока и фактическую стоимость по `usage`.
- Считает три критерия из четырёх машиной; четвёртый — правильность ответа — остаётся человеку.

## Что считается автоматически

| Проверка | Что ловит |
|---|---|
| **регистр** | обращения к пользователю: «используйте», «вы можете», «вам стоит», «это позволит вам», «давайте обсудим» |
| **произношение** | латинские термины и формулы сложности без скобки с русским произношением. Составные термины считаются целиком: `hash map (хеш-мапа)` — один термин, а не два |
| **длина** | строки и слова против правила «максимум 3–4 строки» |
| **преамбула** | «Итак», «Конечно», «Отличный вопрос» в начале |
| **стриминг** | пришёл ответ кусками или одним блоком |

## Ключ

Поле на странице, вписывается перед прогоном. Уходит только на `api.polza.ai` прямо из вкладки — страница локальная и своего сервера не имеет. Галочка «запомнить» кладёт его в `localStorage` этого браузера и по умолчанию выключена.

## Отчёт

Кнопка «Скопировать отчёт» собирает markdown: таблица с цифрами плюс все ответы целиком. Его удобно вставить в чат и разобрать вместе.

## Локальные серверы

Кнопка **«+ Добавить локальный сервер»** — сколько угодно строк, каждая со своим адресом. Подходит любой OpenAI-совместимый: Ollama, LM Studio, llama.cpp, vLLM.

- **Адрес** — до `/v1` включительно: `http://192.168.1.50:11434/v1`.
- **Ключ** — если сервер его спрашивает; локальные обычно нет.
- «Подтянуть модели» читает `/v1/models` и добавляет их в общий каталог с ценой ноль. Дальше они выбираются и прогоняются наравне с облачными — сравнивать имеет смысл только рядом, на одном вопросе и одном промпте.

Адреса запоминаются в `localStorage` и подтягиваются при следующем открытии.

**Если модели не грузятся — почти наверняка CORS**: сервер не пускает браузер. Страница открыта как `file://`, то есть Origin у неё `null`, и это надо разрешить явно:

```bash
OLLAMA_ORIGINS=* ollama serve
```

У LM Studio — галочка CORS в настройках локального сервера. У llama.cpp заголовок открыт по умолчанию.
