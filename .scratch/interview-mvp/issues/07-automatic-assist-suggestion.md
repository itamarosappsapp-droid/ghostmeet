# 07 — Автоподсказка режимом `Assist`

**What to build:** Первый сквозной сценарий продукта. Собеседник задаёт вопрос и замолкает — в ленте сама собой начинает печататься подсказка. Пользователь при этом не нажимает ничего.

Режим — `Assist`: его промпт сам решает, что нужно сейчас, реплика в разговор или решение задачи с экрана.

**Blocked by:** 05 — Канал `Them` через Process Tap; 06 — Настройки и Keychain.

**Status:** ready-for-agent

- [ ] Закрытие реплики `Them` автоматически запускает запрос режимом `Assist`
- [ ] Закрытие реплики `You` запрос не запускает
- [ ] Ответ появляется по мере генерации, а не целиком в конце
- [ ] Лента прокручивается к новой подсказке, последняя визуально выделена
- [ ] Пустой транскрипт не роняет запрос: подставляется плейсхолдер, ответ всё равно приходит
- [ ] Профиль пользователя попадает в системную часть промпта
- [ ] Размер окна транскрипта в промпте соответствует режиму
- [ ] Провайдер скрыт за протоколом и поддерживает отмену запроса на середине
- [ ] Тесты через `SessionEngine` проверяют и факт запуска, и его отсутствие для `You`
