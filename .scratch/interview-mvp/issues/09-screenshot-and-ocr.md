# 09 — Скриншот в каждом запросе и OCR

**What to build:** Подсказка перестаёт быть слепой. К каждому автоматическому запросу прикладывается снимок экрана и распознанный с него текст, поэтому вопрос про код, который сейчас открыт, получает осмысленный ответ. Собственное окно в снимок не попадает — иначе модель увидела бы свой предыдущий ответ.

**Blocked by:** 04 — Окно-оверлей; 07 — Автоподсказка режимом `Assist`.

**Status:** done

- [x] Собственное окно приложения в снимок не попадает — доказано контролируемым опытом, см. ниже
- [x] Текст с экрана извлекается и передаётся вместе со снимком
- [x] Снимок делается достаточно быстро — и, главное, идёт параллельно распознаванию реплики, а не после него
- [x] Ошибка захвата экрана не отменяет подсказку: запрос уходит без снимка, состояние видно в окне

## Comments

**Невидимость своего окна доказана опытом, а не рассуждением.** Две панели собираются одной и той же конфигурацией и отличаются ровно одним свойством — пометкой захвата; в каждой крупный маркер. Дальше снимок боевым кодом и распознавание текста по нему: маркер видимой панели в тексте есть, маркер скрытой — нет, при этом остальной рабочий стол распознан полностью, то есть снимок не пустой. Второй замок (исключение приложения из захвата) намеренно **не** поставлен — он замаскировал бы поломку первого.

**Задержка измерена:** снимок 57–171 мс, распознавание текста 243–670 мс, уменьшение и кодирование 37–110 мс. В путь до первого токена это не добавляется: захват стартует параллельно распознаванию реплики, есть тест с распознавателем, который держится до отмашки.

**Языковая коррекция в распознавании текста отключена намеренно.** С ней `NSURLSession` на экране превращается в `NS URL Session` — то есть код, ради которого режим существует, приезжал бы к модели искажённым.

**Ловушка тестового окружения:** переменные для тест-хоста нужны с префиксом `TEST_RUNNER_`, обычные до него не доезжают.

**Не сделано:** выбор дисплея в многомониторной конфигурации (снимается главный).

Второй долг этого тикета — отменённая подсказка не отменяла уже стартовавший захват экрана, один лишний снимок на перебитую реплику — закрыт тикетом 08: отмена доведена до захвата, проверка стоит до кадра и между кадром и распознаванием текста.
