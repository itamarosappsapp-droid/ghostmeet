# 03 — Распознавание через WhisperKit

**What to build:** Реплики перестают быть безымянными отрезками и получают текст. Пользователь выбирает модель в настройках и видит, что происходит, пока она качается, — а не пустое окно без объяснений.

**Blocked by:** 02 — Захват микрофона и нарезка реплик.

**Status:** ready-for-human

- [x] Закрытая реплика распознаётся, её текст появляется на экране
- [x] Русская и английская речь распознаются без переключения настроек вручную — конструктивно: в каталоге нет одноязычных моделей, определение языка включено на каждой реплике
- [x] Модель выбирается в настройках, выбор сохраняется между запусками
- [x] Пока модель загружается, интерфейс показывает прогресс и остаётся отзывчивым
- [x] Ошибка распознавания не роняет сессию: реплика остаётся в транскрипте помеченной как нераспознанная
- [x] Каналы распознаются независимо друг от друга
- [x] Реализация скрыта за протоколом распознавания; `SessionEngine` не тронут ни строкой, `import WhisperKit` встречается ровно в одном файле

## Comments

22 теста. Настоящая модель ни разу не качалась и не запускалась — тесты работают через фейковый провайдер с режимами «мгновенно / с прогрессом / удерживаемая / падающая», сеть не трогается никогда.

Осознанное решение, которое стоит помнить: **первая реплика первого запуска всегда остаётся без текста**. Реплика, закрытая до готовности модели, отвергается сразу, а не встаёт в очередь — иначе после скачивания вывалилась бы пачка протухших подсказок на вопросы, которые давно прошли. Кнопка «Загрузить модель» в настройках существует именно для того, чтобы этого избежать заранее.

**Требует ручной проверки** — по спеке качество распознавания и есть то, что проверяется вживую: скачать модель, проговорить несколько фраз по-русски и по-английски, убедиться, что текст осмысленный и язык определяется сам.
