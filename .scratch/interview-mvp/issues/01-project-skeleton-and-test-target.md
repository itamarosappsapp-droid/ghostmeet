# 01 — Скелет проекта и тестовый таргет

**What to build:** Проект получает структуру слоёв из спеки и тестовый таргет, в котором можно запускать тесты одной командой. После этого тикета любой следующий начинается с готового места, куда класть код и тесты, а не с перестройки проекта.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Каталоги слоёв созданы согласно структуре проекта из спеки
- [ ] В проекте есть тестовый таргет на Swift Testing, связанный с основным таргетом
- [ ] Команды запуска всех тестов и одного конкретного теста задокументированы в CLAUDE.md
- [ ] Тесты проходят на чистой сборке
- [ ] Артефакты сборки и пользовательские настройки Xcode не попадают в репозиторий
